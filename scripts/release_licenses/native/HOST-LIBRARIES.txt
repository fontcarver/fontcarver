FontCarver Linux host-library notice

FontCarver's Linux desktop uses separately installed system libraries, including
GTK, GLib/GObject/GIO, libsoup and WebKitGTK. These contain LGPL-covered code;
the libraries and their use are covered by their respective library licenses.
Copies of the LGPL version 2 and 2.1 texts accompany this notice. Additional

Debian/Ubuntu. The input deb's Depends field identifies runtime prerequisites.

The maintained deb and thin AppImage use the system's shared-library mechanism;
they do not copy these libraries into the application payload. Users may supply
interface-compatible replacements through their operating system's dynamic
loader. FontCarver's MIT OR Apache-2.0 terms do not impose additional restrictions
on modifying these libraries or reverse engineering for debugging modifications.
The thin AppImage additionally describes its host FUSE/squashfuse usage in
licenses/thin-appimage/README.txt. Libraries and source packages supplied by the

this notice is not a claim that their code is distributed under FontCarver's
