FontCarver Linux host-library notice

FontCarver's Linux desktop uses separately installed system libraries, including
GTK, GLib/GObject/GIO, libsoup and WebKitGTK. These contain LGPL-covered code;
the libraries and their use are covered by their respective library licenses.
Copies of the LGPL version 2 and 2.1 texts accompany this notice. Additional
copyright notices and terms for the exact host versions remain available in the
operating system packages, for example /usr/share/doc/PACKAGE/copyright on
Debian/Ubuntu. The input deb's Depends field identifies runtime prerequisites.

The maintained deb uses the system's shared-library mechanism; it does not copy
these libraries into the application payload, and its Depends field names them.
Users may supply interface-compatible replacements through their operating
system's dynamic loader. FontCarver's MIT OR Apache-2.0 terms do not impose
additional restrictions on modifying these libraries or reverse engineering for
debugging modifications.

The AppImage is different: its bundler copies system libraries into the image.
Those copies are listed per library, with a source reference for each exact
package version, in licenses/appimage/BUNDLED-LIBRARIES.txt inside that image,
alongside unmodified LGPL 2 and LGPL 2.1 texts. Including them does not change
FontCarver's own MIT OR Apache-2.0 terms. A library that is GPL rather than LGPL,
or whose license cannot be identified, blocks the release instead of shipping.

Libraries and source packages supplied by the operating system remain the
responsibility of that distribution's packages; this notice is not a claim that
their code is distributed under FontCarver's own license.
