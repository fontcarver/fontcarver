FontCarver
能力 格式 使用方法 下载 GitHub English

绘制轮廓，编辑点阵，导出 OpenType。

FontCarver 是一款内核以 Rust 写成的桌面字体编辑器。轮廓与点阵字型存在于同一份文档；一套 65,535 字的中日韩字库，用的是与单母版拉丁字体相同的工具；你没有动过的表，会原样从导出器里出来。

早期开发阶段。P0 至 P4 已在各自验收报告界定的范围内完成，P5 仍在进行，目前还没有打包发布。 查看状态记录

§1
能力

四件不被当作后补功能来对待的事。

多数编辑器围绕一种字体形态建成，其余的后来再补。这里的文档模型从一开始就同时包含这四者。

曲线与点阵，同一份文档

三次与二次曲线的轮廓编辑，和点阵字型编辑，是同一份文档，而不是两个程序。可以把点阵描摹成轮廓，把轮廓栅格化成字型，再逐像素手工修整。

拉丁与中日韩，同一套工具

字形网格、搜索、批量操作与文件读写，都是按 65,535 字的规模设计的。部件、纵向度量与纵排布局特性属于模型本身，而不是插件。

读得懂的 OpenType 布局

GSUB、GPOS、GDEF、BASE、MATH、STAT、COLR 与 CPAL，既可以作为特性文件源码编辑，也可以通过界面编辑，由 fea-rs 与 fontc 编译，诊断信息定位到你自己的源码行上。

没动过的地方，不会被改写

模型未涵盖的表，在打开与导出之间原样保留；你没有编辑过的字形，保留其 hinting。打开一份字体，不是一次有损操作。

§3
使用方法

一次完整的上手过程。

四步，从一份现成的字体，到一份你自己导出的字体。按键以 Windows 与 Linux 标注；在 macOS 上，Ctrl 即 ⌘。

打开字体

打开 TTF、OTF、UFO、Glyphs 或 SFD 文件，也可以打开 FontCarver 文档。模型无法表达的部分会原样保留而不是丢弃，所以你可以只为了看一眼而打开一份字体。

  • CtrlO 打开
  • CtrlShiftP 命令面板

编辑轮廓

用钢笔绘制，用刻刀切割，用方向键微调节点。平滑点的两条控制柄保持共线，角点则不必，所有编辑都走同一个撤销栈。

  • V 选择
  • P 钢笔
  • B 铅笔
  • E 刻刀
  • CtrlZ 撤销

先调字距，再加特性

在文本标签页里，直接在两个字形之间的空隙上调字距，支持共享分组与逐母版的字偶对。其余的部分写成特性文件源码，编译器的诊断会落在你自己的行上。

  • CtrlI 字体信息
  • T 文本工具

导出

写回 TTF 或 OTF。你没有编辑过的字形保留其 hinting，被保留的表会合并回去。目前编辑轮廓会丢掉该字形的 hinting，状态记录里写明了这一项的进展。

  • CtrlS 保存
  • CtrlE 导出
$ fontcarver inspect DejaVuSans.ttf        # 元数据与被保留的表
$ fontcarver check Source.fcf              # 查找问题，有错误时退出码为 1
$ fontcarver convert Source.glyphs Source.ufo
$ fontcarver build Source.fcf Source.otf --autohint
$ fontcarver shape Source.fcf "Hamburgefonstiv" --features liga,-kern

从源码构建

需要 rust-toolchain.toml 中固定的 Rust 版本、Node 24 及以上、pnpm，以及 Tauri 的系统库。在 Debian 与 Ubuntu 上是 libwebkit2gtk-4.1-dev、 libgtk-3-dev、libayatana-appindicator3-dev 和 librsvg2-dev。 

$ git clone https://github.com/fontcarver/fontcarver.git
$ cd fontcarver
$ pnpm install
$ pnpm tauri dev                          # 运行编辑器
$ cargo test --workspace                  # Rust 内核的测试

§5
状态

工作实际进展到哪里。

「完成」指的是在该阶段验收报告界定的边界内完成，而不是穷尽所有情况。到目前为止，原生桌面输入自动化与发布打包在每个阶段都尚未验证。

  1. P0外壳、无损往返、字形网格
  2. P1轮廓编辑、工具、导出
  3. P2字距、可编辑 OpenType 布局、源格式
  4. P3点阵字型与点阵格式
  5. P4可变字体、汉字构造、纵排
  6. P5专业收尾、hinting、打包

有一个已知缺陷尚未解决：一项藏文布局扩展预算测试失败，在诊断清楚之前，工作区测试套件不被称作全绿。这一项以及其他所有事项，都记录在 状态记录里。

FontCarver

一个从零实现的字体编辑器，以 Apache-2.0 与 MIT 双许可发布。构建在采用宽松许可的 Rust 字体生态之上：fontations、fontc、kurbo、fea-rs、harfrust、norad 与 tiny-skia。
