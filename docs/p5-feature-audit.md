# P5 professional feature audit

Status: open. This is the complete Must-have/Should-have exit checklist from
`docs/research/competitor-ux.md` section 12. An existing file, control or API is not
sufficient evidence of completion. Each row needs a working editing path,
persistence/export where relevant, and direct verification. Pending rows are not
claimed complete. P1–P4 evidence may be reused after checking its exact scope.

The 2026-09-30 resumed batch is recorded in [the integration
checkpoint](p5-resume-integration.md). **Completion wave 1** (shell, glyph
inventory, outline editor, metrics/spacing/kerning, OpenType features, font
info/design space/export/CLI, cross-document/scripting/plugins, release) was
implemented, reviewed, fix-rounded and integrated on 2026-09-30; each row below
links the acceptance document that carries its commands, browser evidence and
limits. A row is Complete only where its acceptance document recommends Complete
and no blocking review defect remains; the qualifier in the evidence column is
part of the claim.

Counts: **75 Complete, 5 Partial, 32 Pending verification** of 112 rows (before
wave 1: 3 Complete, 3 Partial, 106 Pending verification). Pending statuses are
deliberately retained where complete workflow acceptance is missing; they do not
mean that the implementation is absent. Wave 2 (bitmap, proofing, construction,
hinting, CJK, help) is planned and not started.

One regression found while integrating is **not fixed** and belongs to no single
row: typed text in the Text tab is sometimes dropped before it is shaped, so the
click that enters local edit mode on a shaped glyph then does nothing
(`app/e2e/text.spec.ts:122`). It is recorded in [TODO](TODO.md); the rows below
are not claimed against it.
