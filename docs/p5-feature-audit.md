claimed complete. P1–P4 evidence may be reused after checking its exact scope.

## Additional P5 design requirements

The approved product design also requires MATH authoring, which has no dedicated
row in the 112-item competitor checklist above. Completing it does not mark any
broader checklist row complete.

| Requirement                                            | Status                                      | Evidence / boundaries                                                                                                                                                                                                                                                                                                                                                             |
| ------------------------------------------------------ | ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| MATH constants, glyph records, variants and assemblies | Complete                                    | [Acceptance](p5-math-acceptance.md): bilingual editor, validation, undo/redo, FCF save/reopen, TTF/OTF/WOFF/WOFF2 exports; independent FontTools/HarfBuzz checks on DejaVu Sans and DejaVu Math TeX Gyre. Static corpus; variable paths have Rust integration coverage. Ordinary Device corrections only; full expression layout and native desktop input are outside this block. |
| Static OpenType SVG documents                          | Complete within static subset               | [Acceptance](p5-svg-acceptance.md): named bindings/source editor, bounded plain/gzip codecs, ID remapping, undo/native/UFO persistence, four export containers and independent FontTools/XML checks. Filters, images, stylesheets, animation, CPAL-injected preview and native rendering remain outside this boundary.                                                            |
| Static COLRv1 paint graphs                             | Complete within static subset               | [Acceptance](p5-colrv1-acceptance.md): all static paint formats, source editor/preview, shared palettes, undo/native/UFO persistence, eight independent binary/pixel comparisons. Variable paints remain raw; grid/text and native-platform color rendering are outside this boundary.                                                                                            |
| Batch style transformations                            | Complete within baked master-outline subset | [Acceptance](p5-style-effects-acceptance.md): eight editable presets, bounded revision-checked batch preview/apply, original-source component decomposition, anchors/advances/backups, undo/native/export, independent synthetic and real-font checks. Does not close rows 87/88 for live non-destructive effects.                                                                |
