# P5 professional feature audit

Status: open. This is the complete Must-have/Should-have exit checklist from
`docs/research/competitor-ux.md` section 12. An existing file, control or API is not
sufficient evidence of completion. Each row needs a working editing path,
persistence/export where relevant, and direct verification. Pending rows are not
claimed complete. P1–P4 evidence may be reused after checking its exact scope.

The 2026-09-30 resumed batch is recorded in [the integration
checkpoint](p5-resume-integration.md). **Completion wave 1** (shell, glyph
inventory, outline editor, metrics/spacing/kerning, OpenType features, font
info/design space/export/CLI, cross-document/scripting/plugins, release) was
implemented, reviewed, fix-rounded and integrated on 2026-09-30, and
**completion wave 2** (bitmap, proofing, construction, hinting, CJK, help) on
2026-10-01; each row below links the acceptance document that carries its
commands, browser evidence and limits. A row is Complete only where its
acceptance document recommends Complete and no blocking review defect remains;
the qualifier in the evidence column is part of the claim.

Counts: **110 Complete, 2 Partial, 0 Pending verification** of 112 rows (after
wave 1: 75 Complete, 5 Partial, 32 Pending verification; before wave 1: 3
Complete, 3 Partial, 106 Pending verification). The two Partial rows are 9 and
62, both waiting on native macOS/Windows execution. Wave 3 rebuilt the actual
Linux candidates, passed isolated APT install/reinstall/removal and replaced the
old AppImage with a verified thin image using host libraries. Current evidence
and remaining delivery work are in [TODO](TODO.md) and
[integrated acceptance](p5f-w3-integration-acceptance.md). No row is
closed by a passing test suite alone, and no row is Pending any more: every
requirement now has either an acceptance document or a stated missing piece.

The later local UX/welcome pass is verified at **`f6f6cf9`**, with **2,914 frontend
tests and 105/105 browser tests**. It adds compact-layout, gesture and focus
repairs plus welcome-page discovery, without changing the bounded row counts.
See [actual experience](p5ux-experience-acceptance.md) and
[welcome acceptance](p5ux-start-discovery-browser-acceptance.md).

The intermittent Text-tab failure recorded here after wave 1
(`app/e2e/text.spec.ts:122`) was diagnosed in wave 2: it was the cold first
`text.shape` compile, about four seconds, not dropped input. The spec now waits
on `data-text-shaping` and the row claims below are unaffected
