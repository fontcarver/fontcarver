## New Breakage in the Fix Diff

- **Minor — `TransformSelection` is no longer fully atomic on a validation failure.** `outline::apply` (`crates/fw-doc/src/command/outline.rs:22-28`) captures and restores only `layer.contours`, but `points::transform_selection` (`crates/fw-doc/src/command/outline/points.rs:140-183`) also mutates `layer.components[*].transform` and `layer.anchors`. If `validate` fails, the command reports `InvalidCommand` while the component transforms and anchor positions stay moved. `Document::apply` does not roll back single (non-`Batch`) commands (`crates/fw-doc/src/command/apply.rs:204-217` only restores for `Batch`), so nothing else catches it. Reachable only when the layer already holds a contour that `try_to_bezpath` rejects (an affine transform of a well-formed contour stays well-formed), so no shipped test hits it — but the same pre-condition makes it deterministic rather than exotic.
- **Minor — `validate` checks every contour of the layer, not only the touched ones** (`outline.rs:34-37`). One pre-existing malformed contour anywhere in a layer therefore makes *every* outline command on that layer fail with `InvalidCommand`, including commands on unrelated contours; the model itself tolerates such contours (`Contour::to_bezpath` has an unchecked fallback), so they can arrive from an import. The dispatch's ruling 4 said "each touched contour".
- **Minor — `AddContour`'s error class changed.** `segments.rs:14-24` dropped the direct `contour.try_to_bezpath()?`; a malformed contour is now reported by the shared validator as `Error::InvalidCommand` instead of `Error::Model(MalformedContour)`. Externally identical after fw-api mapping (both → `invalid_params`), but it is a behaviour change for any in-process consumer matching on the variant.
- **Minor — per-command clone of the layer's contours.** `outline.rs:22` clones all contours on every outline command, i.e. on each `preview_edit` frame of a drag. Correct, but it turns a previously O(selection) preview into O(glyph).

No panic path found in the new code. I walked the degenerate cases the scope calls out: empty contour (`keep_shape` delete.rs:107 returns `None`), 1–2 point contours (`sole_survivor` delete.rs:198 and the `< 2 on-curve` reject in `convert`), all-off-curve closed contours (`on_curves.is_empty()` → `simple`, delete.rs:108-109), open contours (head/tail run branches, delete.rs:139-158, both using `get`/`checked_sub`), and wrap-around runs (`runs` delete.rs:228-238, with `cyclic_between` bounded by `result.len() < len`, outline.rs:214). Every index into `contour.points` in the new code is either from `validate_points`-checked input or from `on_curve_indices`; the rest use `get`. `fit_span` has no fallible return and no unchecked slicing (`points.get(1..len.saturating_sub(1)).unwrap_or_default()`, fit.rs:107-110); `Line::nearest` on a zero-length chord returns `t = 0` rather than NaN. `ConvertSegment`'s modulo handling is correct for the wrapping last segment: the controls between `start` and `end` are removed cyclically and the new ones are appended after `start` at the array tail, which is the correct stored position and does not move the first on-curve point.

Apply/undo exactness is unaffected by the rewrite: undo is whole-glyph (`Snapshot::Glyph`, `crates/fw-doc/src/undo.rs:198-224`), so it restores components and anchors regardless of what a command touched.

## Out-of-Scope Observations

- `inferred_kind` (`outline.rs:167-173`) infers quadratic from `contours.iter().any(Contour::is_quadratic)`. A glyph in a TrueType font whose layer holds only straight contours infers `Cubic`, so a later `DeletePoints`/`ConvertSegment` there would insert cubic handles into a quadratic font. Pre-existing heuristic (it already backed `PathOp`), now also relied on by delete/convert. Not exercised by the corpus (all six glyphs have curves).
- The corpus sweep measures deviation one-way (original span samples → resulting contour, `delete_points.rs:398-406`). It would not catch a fitted segment that bulges away from the original between samples of the *new* curve. The p90/max thresholds make this academic for the shipped fitter.
