## Rulings (binding)
1. **Panel architecture**: `app/src/views/glyph/panels/{GlyphPanel,MetricsPanel,LayersPanel,ComponentsPanel,AnchorsPanel,GuidesPanel,TransformPanel}.tsx` (≤ 450 lines each) rendered by an `EditInspector.tsx` accordion in the §7 order; open/closed state per panel persisted in `uiStore` (localStorage-backed if P0 has that pattern, else session-only); count badges from the outline. Every field commit is one `doc.apply` command with a human undo label (§10); no panel keeps its own copy of document state — read from the glyph detail/outline hooks and the editor store.
2. **Glyph panel** (§7.1): name (RenameGlyph), unicodes chips + add (SetUnicodes), category/sub-category/script read-only derived (use fw-glyphdata through the existing detail if exposed; else omit with a note), export toggle + colour label + tags + note via `SetGlyphMeta` (only the fields `SetGlyphMeta` supports — read the binding).
3. **Metrics panel** (§7.2): width/LSB/RSB fields → `SetMetrics`; metrics keys row (`=H`, `=|n`, `=n+10`) → `SetMetricsKeys`, live resolved value via `doc.metrics_resolve`, "out of sync" badge when the resolved value differs from the stored sidebearing, "Apply" writes the resolved values with `SetMetrics`. **Canvas sidebearing handles**: draggable LSB/RSB/width handles at the metrics lines (`metricsHandles.ts`: hit test + drag through the edit-session protocol as `SetMetrics` steps, one undo entry per drag, HUD shows the value) — add the minimal hook in the controller (a `metrics` hit kind routed to a small gesture module you own).
4. **Layers panel** (§7.3): masters (bold), brace/bracket, backgrounds, backups (timestamped); add background (`AddLayer`), copy to background (`CopyLayer`), swap with background (`SwapWithBackground`), add backup, delete (`RemoveLayer`, never a master); eye toggles for background/other-masters overlays (editor store overlay flags exist from P0/T6 — reuse). Selecting a layer row switches the edited layer (the outline hook takes a `layer` id).
5. **Components panel** (§7.4): list (name, offset, scale), drag reorder (`SetComponent` order or `RemoveComponents`+`AddComponent` batch — pick what the commands allow and say so), add via a search popover reusing `glyphs.search` with cell thumbnails, decompose (`DecomposeComponents`), "open base" (new Edit tab), auto-align toggle and use-my-metrics if the model has them (read `Component.ts`; omit with a note if not). Double-click on a component on canvas opens the base glyph.
6. **Anchors panel** (§7.5): list, add with name suggestions (`top`, `bottom`, `ogonek`, `_top`, `_bottom`, `entry`, `exit` + fw-glyphdata defaults if exposed), delete; row click selects the anchor on canvas; anchors draggable on canvas through the existing drag plan (Task 6 previews anchors in the transform regime) — verify and fix if an anchor-only drag does not commit `SetAnchor`/`TransformSelection`.
7. **Guides panel** (§7.6): local/global lists (position, angle, name, lock, measurement toggle); Alt+drag from a ruler creates a guide (`AddGuide`, scope local; Shift for global via `SetFontGuides` if that is the global mechanism — read the bindings); angle knob when selected; locked guides dashed.
8. **Transform panel** (§7.7): move/scale/rotate/skew with 9-point origin picker + custom, flip H/V, "Apply" = one `TransformSelection` (affine composed locally); align/distribute row for multi-selection (compute targets locally, commit one `Batch` of `MovePoints`/`SetPointPosition`). Nothing selected → whole layer.
9. **Path menu** (§11): Remove Overlap (`Mod+⇧+O`), Correct Direction (`Mod+⇧+R`), Add Extremes (`Mod+⇧+E`), Add Inflections, Simplify… (small inline dialog for `SimplifyOptions`), Round to Grid, Reverse, Set Start Point (uses the selected node), Tidy (`Mod+⇧+T` = canonical start + order), Expand Stroke… (dialog for `StrokeOptions`), Convert to Cubic/Quadratic, Join (`Mod+J` = `JoinContours` on two selected open ends), Break. All through `doc.apply(PathOp|…)` on the selected contours (or all), undoable with labels. Glyph menu: Duplicate (`DuplicateGlyph`), Add Glyphs… (opens the Task 9a dialog), Decompose all, Previous/Next glyph (`Mod+[`/`]`). Layer menu: the Layers-panel actions.
10. **Edit-tab sidebar** (§3): Layers list on top (same component as the panel's list, compact), compact glyph list below reusing the Font view's grid at a small cell size and the current Font-view filter; clicking a glyph switches the Edit tab's glyph (keep the tab, replace the glyph) — deferred from Task 6.
11. **Canvas markers deferred from Task 6**: node on a vertical metric = 7 px diamond (§4.1 item 9); locked-component hatch on hover and the component origin marker/name label collision avoidance (§4.1 item 6); guide angle knob and measurement-guide intersection distances (§4.1 item 12).
12. **Undo labels + status flash** exist (Task 6); every new command gets a label key. i18n: keys in `en.json`, same keys in `zh-CN.json` with English placeholders, listed for Task 13. Do not translate.
13. Files ≤ 450 lines (800 hard cap); no Rust changes; transport-only; Zustand only; Prettier/ESLint clean.
