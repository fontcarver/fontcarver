## Rulings (binding)
1. **Tool state machines live in `app/src/editor/tools/<tool>.ts`** as pure reducers/handlers (pointer/key events + editor context in, commands/previews out) so each is unit-testable with plain objects; the controller only routes events to the active tool. Do not grow `editorController.ts`; extract routing if needed.
2. **Pen**: accumulates points locally with a live preview (rubber-band segment, handle drag on press-drag, Alt = outgoing handle only, Space held = reposition the last node, Shift constrains); commits ONE `AddContour` (one undo entry) when the path closes (click on the first node) or finishes (Enter, tool switch, Escape with ≥ 2 nodes; Escape with < 2 cancels). Clicking an end node of an existing open contour continues it: the result is committed as a `Batch` of `DeleteContours` + `AddContour` (one undo entry, label "Extend path"). Curve kind follows the layer (quadratic layers get quadratic segments: one off-curve per segment, dragged handle mirrored to the control point).
3. **Pencil**: freehand samples (min 2 px apart) → `Batch([AddContour(polyline), PathOp::Simplify(that contour, error from prefs or 1.0)])`, one undo entry "Draw"; Shift makes straight segments between clicks.
4. **Knife**: compute locally: intersections of the drag line with the flattened outline (16 samples per curved segment, then refine on the exact Bézier by bisection), insert nodes at the intersections, and (a) open contours: split at the nodes; (b) closed contours with an even number of intersections: cut into closed pieces by joining consecutive cut points with a straight segment (Glyphs behaviour). Commit as a `Batch` of `DeleteContours` + `AddContour`s (one undo entry "Cut"). Test: a rectangle cut by a vertical line → two closed 4-point contours; an open path cut once → two open paths.
5. **Shapes**: Rectangle (F) / Ellipse (Shift+F) by drag (Shift = square/circle, Alt = from centre); click without drag opens the numeric dialog (x, y, w, h; Enter creates); ellipse = 4 cubic segments with kappa 0.5522847 on cubic layers, 8 quadratic segments on quadratic layers; committed as `AddContour` with the layer's winding direction (TrueType clockwise outer, PostScript counter-clockwise — read the kernel's `CurveKind`/font declaration through `LayerOutline` if it exposes it, else infer from the outline's point kinds and default to clockwise for quadratic).
6. **Measure (L)**: drag shows in the HUD distance, angle and, along the drag line, the intersections with the flattened outline with per-span distances drawn on canvas (§5, §6.2); Shift constrains. Purely local; no commands.
7. **Rotate (R) / Scale (S)**: first click sets the origin (default: selection centre; marker drawn), drag rotates/scales the selection with live optimistic preview, committed through the edit-session protocol as `TransformSelection` steps (same per-frame step protocol as MovePoints); Shift constrains (15° / uniform); HUD shows angle or %; nothing selected → the whole layer.
8. **Zoom / Hand**: already live from Task 6; make them conform to §5 (Zoom: click in, Alt-click out, drag = marquee zoom) if anything is missing.
9. **Tap/hold** exists from Task 6; verify every tool key in §5 (V P B E F ⇧F L R S Z H T) and add the missing ones; T (Text) registers but stays inert until Task 9.
10. **Snapping completion**: grid (from `prefs.grid_size` when > 0 and `snap.grid`; draw the grid per §4.1 item 1), component ghost nodes (from `glyphs.flattened_components`, `snap.components`), magnetic alignment lines to other nodes' x/y (exists — verify), all distances from prefs (`prefs.get` once, refreshed on the prefs-changed event if there is one; otherwise on tab mount). Snap order per §4.2: node > handle > anchor > guide > metric > grid > alignment line. The snapping flag in the editor store (`view.toggleSnapping`) is honoured by every tool.
11. **Custom SVG cursors (§2.4)** for pen (+ / × / ○ variants), knife, measure, rotate, scale, insert-node and break-handle: 24 px, 1 px dark outline + white fill, inline `data:` URIs generated from small SVG strings in `app/src/editor/cursors.ts`; DPR-independent; fall back to the standard cursor names when the platform rejects custom cursors.

## Carried from Task 6 (REQUIRED in this task; see task-6-rereview3.md "New Breakage" for probes and file:line)
A. **Gate coverage for every gesture close.** The nudge gate only covers a close the nudge runner starts itself. An arrow press one kernel round trip after a settle-/endNudge-/drag-driven close (and drag→drag: `pointerDown` overwrites a live drag whose `edit_end` never ran) still sends `edit_begin` ahead of the previous gesture's pending `edit_apply` → `InvalidEditToken`, a dropped apply and a preview that stands ahead of the document. Fix: thread `after: this.closing` into `NudgePress`, set `this.closing` in `finishDrag` (and on any drag replacement) exactly as `settle()` does, and make every tool's pointer-down go through the same gate. Regression tests on the token-checking mock transport (`app/src/test/mockTransport.ts` `createEditingTransport`) for: settle-close → arrow, pointer-up → arrow, drag → drag, tool switch mid-run.
B. **Component preview on the canvas.** `EditorFrame.components` (preview offsets under the transform regime) has no canvas consumer: `GlyphCanvas` draws components from the fetched scene, so a dragged component moves in the Info box but not on screen; `hitInput()`/`frame()` also use the source components. Draw the per-component paths from the preview (LayerOutline already carries per-component data — stop relying on the single flattened path for the ghost), and feed the hit test/frame the previewed components.
C. **Split `gestures/drag.ts` (751 lines, three delta regimes)** into ≤ 450-line modules (e.g. `drag/plan.ts`, `drag/deltas.ts`, `drag/preview.ts`, `drag/commands.ts`) with no behaviour change — the existing drag tests must pass unchanged.
D. Trivial, do if touching the code anyway: `editOutline()` rebuild twice per pointer move (identity check misses on fresh arrays — cache per preview object); mock `doc.undo` should finalise the active edit like the kernel; the idle-timer close clears `carried` while its reload is in flight; `closeNudge` mid-drag clears the drag preview for one frame.
