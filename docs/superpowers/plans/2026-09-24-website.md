## Not published

`.github/workflows/site.yml` deploys only when all three hold: the event is not
a pull request, the ref is `refs/heads/main`, and the repository variable
`CLOUDFLARE_PAGES_PROJECT` is set. The variable does not exist, so merging this
branch publishes nothing. The setup checklist is in
[`site/README.md`](../../../site/README.md).
