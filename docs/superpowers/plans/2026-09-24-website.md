# Website implementation — progress

Branch `site`. Design: [`specs/2026-09-24-website-design.md`](../specs/2026-09-24-website-design.md).

## Done

- `site/tools/extract-outlines.py` — reads OFL fonts with fontTools, records real
  outlines (segment types, corner/smooth classification), rasterises baseline-aligned
  strikes at 12/16/24 ppem. Run:

  ```sh
  python3 site/tools/extract-outlines.py \
      --latin <source-serif-4-variable.woff2> \
      --cjk /usr/share/fonts/opentype/noto/NotoSerifCJK-Regular.ttc --cjk-font-number 2
  ```

- `site/assets/js/specimens.js` — generated: `g` from Source Serif 4 Regular
  (35 on-curve points, quadratic, advance 518/1000) and `永` from Noto Serif CJK SC
  (36 on-curve points, cubic, advance 1000/1000).
- `site/assets/fonts/` — subset woff2: Source Serif 4 variable (wght 200–900,
  opsz 8–60, 70 KB), IBM Plex Mono 400 and 500 (5 KB each).
- `site/assets/css/tokens.css`, `site/assets/css/site.css` — full design system.
- `site/index.html` — complete English page. The hero figure is not injected yet;
  it sits between the `hero:begin` / `hero:end` markers.
- `site/assets/js/theme.js`, `site/assets/js/site.js` — theme and platform detection.

## Decisions already taken

- Two type voices only: serif for prose, monospace for anything the machine knows.
  No sans anywhere.
- Palette inherited from `app/src/styles/tokens.css`; the hero stage is dark in
  both themes and uses the application's `--cv-*` canvas colours.
- No product screenshots: `docs/screenshots/` still carries the old FontWorkshop
  branding.
- Download section ships in a `pending` state; going live is one data block and
  one attribute.
- Deploy is gated on: not a pull request, `refs/heads/main`, and a repository
  variable that does not exist yet.
