# P5 bounded EPS glyph interchange

## Scope and ownership

Implement `crates/fc-formats/src/vector/eps.rs` and its unit tests. The vector
coordinator owns registration, public dispatch, shared validation, SVG and
dependencies. No other format, API or UI files are owned here.

Interfaces: `read(&Path) -> Result<Font, Error>` and
`write(&Font, &MasterId, &GlyphName, &Path) -> Result<(), Error>`, visible to the
parent module. Export exactly the requested main-layer outline.

## Behaviour and limits

Read the EPS DSC header and bounded literal `newpath`, `moveto`, `lineto`,
`curveto`, `closepath`, `fill` declarations; never execute imported PostScript.
Reject arbitrary operators, executable procedures, unsupported paint operations,
unpainted outlines, invalid operands and non-finite or excessive coordinates.
Use the shared 32 MiB input cap and a one-million operation cap. Preserve
glyph name, advance and UPEM in inert DSC comments; accept ordinary bounded EPS
without those private comments as one `glyph`. Emit standalone declarative EPS
and atomically replace the output only after validation succeeds.

## Acceptance

Write failing tests first for a cubic outline and metadata round trip, plain
third-party-style declarative input, malformed/operator rejection, and
destination preservation on invalid export. Verify multiple contours and
quadratic-to-cubic export. If Ghostscript is installed, validate only our own
known-safe generated bytes through its parser. Run focused Cargo tests under
the shared Cargo lock and normal profiles, with task-specific TMPDIR. Parent
performs integrated Clippy/regression checks. Check artifacts at start and finish.
