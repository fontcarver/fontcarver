2. **DeletePoints KeepShape** (Critical 2, 3): reimplement as one pass per contour with no `rotate_left`:
   - Group the on-curve nodes to delete into maximal runs along the contour; for each run, the surviving neighbours P (before) and Q (after) get ONE new segment: line if both adjacent original segments were lines; otherwise a fitted curve whose tangent at P is the original outgoing tangent at P and at Q the original incoming tangent at Q. Fit = least-squares handle lengths along the fixed tangents against the sampled original span (e.g. 32 samples per original segment); for quadratic layers a single quad with the control point at the tangent intersection (parallel/behind → line). Add this as an ADDITIVE API in fw-geom `edit.rs`: `fit_span(samples: &[Point], tan_in: Vec2, tan_out: Vec2, kind: CurveKind) -> Segment`-style (name/shape yours, documented, tested with a synthetic arc). It must never fail for valid input (no `Error::Geometry` for a legal deletion).
   - Off-curve points listed for deletion: convert the owning segment to a line (Glyphs behaviour).
   - Contour start point is preserved unless it is deleted, in which case the next surviving on-curve node becomes the start. Deleting every point of a contour removes the contour. Open contours: deleting an end node just drops it (no fit).
   - `DeleteMode::Simple` removes the listed points and their handles with no fit (as before).
   - Tests: insert-then-delete round trip ≤ 1 unit; line+line → line with 1 point fewer; a corpus sweep over DejaVu `B O S a e g` deleting every on-curve node one at a time asserting `Ok` for all and printing max/median deviation (assert median ≤ 2 % of the joined span's chord, max ≤ 15 %); multi-point run deletion; delete-all → contour removed; closed quadratic contour stays all-quadratic (no cubic handles).
