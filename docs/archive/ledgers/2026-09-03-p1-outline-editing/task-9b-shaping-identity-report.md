# T9b shaping identity report — 2026-09-07

Implemented in `p1-text-kernel` commit `84596c0 fix(fc-layout): retain compiled glyph identities`.

`fc-compile` now exposes `compile_static_with_metadata`, returning the compiled bytes plus the exact model glyph names in compiled-GID order. The existing `compile_static` byte-returning API remains compatible. Identity is captured from generated bytes before the large-font `post` format 3 conversion, reused by the patching path, and validated against the compiled glyph count.

`fc-layout::CompiledFont` consumes this retained order for cmap and shaping names while continuing to read advances from `hmtx`. This keeps production-name mapping, inserted `.notdef`, excluded glyphs, and substitutions safe without treating compiled GIDs as document handles or guessing names from input.
