## Decisions (do not revisit)
- **fw-layout**: `Shaper` holds a compiled in-memory font per (document, master) built with `fw_compile::compile_static` (no preservation, features from the model, kerning/anchors auto), keyed by a `layout_generation` = (glyph set/order, kerning, features, metrics generations — derive from `Document` generations: any `Change` with `glyph_order || kerning || font_info || masters`, or glyphs touched). Outline-only edits do NOT trigger a recompile for shaping purposes (advances come from the model widths — rebuild only `hmtx` in-memory? Simpler ruling: outline+width edits bump a cheap "advance" refresh: recompile is debounced 300 ms on a background thread; until it lands, `text.shape` serves the previous font with `stale: true`). `text.shape` returns advances from the compiled font plus, for glyphs whose width changed since compile, the model width (so metrics editing feels instant).
- **API methods** exactly as the brief's table: `glyphs.outline`, `glyphs.flattened_components`, `glyphs.add` (recipes: ranges `A-Z`, `uni4E00-uni4E1F`, names with suffixes `a.sc`, ligatures `f_i`, `@charset:GB2312` etc. via fw-glyphdata; skipped = already present or unknown), `glyphs.ids`, `doc.metrics_resolve`, `text.shape`, `session.export` (emits `ProgressEvent { doc, stage: "compile"|"preserve"|"write", percent }` on the existing event stream — extend `DocumentEvent` into an enum `Event { Document(..), Progress(..) }` additively with `#[serde(tag = "kind")]`; keep the TS name `DocumentEvent` for the document variant to avoid churn), `session.recover_list/recover/discard_recovery`, `prefs` fields, and `doc.apply` accepting every Task 2 command (TS union regenerated). `session.open` gains UFO/designspace (`.ufo` dir, `.designspace`), `session.save` unchanged (fwf only), `session.export` handles `Ttf|Woff|Woff2|Ufo|Designspace|Fwf`.
- Touched-glyph detection for export: pass the real per-glyph generations from `Document` (`glyph_generation(gid) > import generation` — record the import generation in `Document`), and additionally the content-hash safety net: `fw_compile::touched_since_import` gets an optional hash comparison — implement `Document::glyph_content_hash(gid)` (sha1 of the serialized master layer) captured at open and compared at export; a glyph is touched if either signal says so.
- **Autosave** wired: `Session::new_with_prefs(prefs)` starts `fw_doc::autosave::spawn` with `Prefs.autosave_seconds` (0 disables); `session.recover_list` lists `list_recoverable`; `recover` opens the sidecar as a new document keeping the original path as "recovered from"; `discard_recovery` deletes the sidecar.
- **CLI**: `fw build <in> <out.(ttf|woff|woff2)> [--remove-overlap] [--no-preserve] [--master NAME]`, `fw convert` gains `.ufo`/`.designspace` in and out and binary out via `build`'s pipeline, `fw shape <font|fwf> <text> [--features kern,liga] [--master NAME]` printing `gid name x_adv y_adv x_off y_off cluster` lines.
