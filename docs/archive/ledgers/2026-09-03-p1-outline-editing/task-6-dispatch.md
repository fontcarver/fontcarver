## Interfaces you consume (kernel, already merged)
- `glyphs.outline` (`LayerOutlineParams { doc, glyph, layer? }` → `LayerOutline { contours, components, anchors, guides, width, lsb, rsb, resolved_metrics, layer, master, bbox }`) — the editable outline of one layer; `glyphs.flattened_components` for component hit ghosts.
- Gesture protocol: `doc.edit_begin { doc, label }` → `EditTokenId`; `doc.edit_apply { doc, token, command }` (coalesces into ONE undo entry per token; may be called per animation frame); `doc.edit_end { doc, token }` finalises; a stale token → `invalid_params`. `doc.apply { doc, command }` for single-shot commands (one undo entry each).
- Commands (`Command.ts`, externally tagged): `MovePoints { glyph, layer, points: PointRef[], dx, dy, handles: "WithHandles" | "PointsOnly" }`, `SetPointPosition`, `SetSmooth`, `InsertPointOnSegment`, `DeletePoints { mode: "KeepShape" | "BreakContour" | "Simple" }`, `ConvertSegment { to: "Line" | "Curve" }`, `SetStartPoint`, `ReverseContours`, `TransformSelection`, `SetComponent`, `SetAnchor`, `SetGuide`, `SetMetrics`, `Batch`. Read the generated file for exact field names — do not guess.
- Events: `fw:event` stream delivers `Event = {kind:"Document"} & DocumentEvent | {kind:"Progress"} & ProgressEvent`; a `Change` result says what to refetch (`glyphs`, `metrics`, `layers`, `guides`…). After every `edit_apply` result you refetch nothing during the drag (optimistic local geometry); on `edit_end` refetch `glyphs.outline` once and reconcile.

## Rulings (binding; resolve brief/spec disagreements)
1. Snap distance 6 px, snapping order per §4.2, Ctrl held suspends snapping. Write the tests against these numbers.
2. Fixtures: the brief's "Nimbus `o`" no longer exists (fixtures were relicensed). Screenshots: `docs/screenshots/p1-select-{drag,handles,infobox}.png` on DejaVu `g` plus `p1-select-cubic.png` on Source Serif `o`.
3. Drag protocol: pointer-down on a selectable target → `doc.edit_begin` with a human label (`Move 3 points`, `Move handle`, `Reshape segment`); the local outline updates optimistically every pointer-move (no round trip); `doc.edit_apply(MovePoints)` sends the cumulative delta relative to the gesture start at most once per animation frame (throttle with `requestAnimationFrame`; a moved-then-not-moved gesture sends nothing and calls `edit_end` — no undo entry); pointer-up → last `edit_apply` if pending, then `doc.edit_end`. Escape during a drag: `edit_end` then `doc.undo`-equivalent (use the existing undo command) so the gesture is cancelled; document this in code.
4. Nudges: arrow keys coalesce within 500 ms into one undo entry using the same token protocol (`edit_begin` on the first key, `edit_apply` per key, `edit_end` after 500 ms of silence or on any other action).
